Tentang Coding Club

Coding Club SMKN 1 Subang adalah kegiatan yang membantu siswa mengenal dunia pemrograman dan teknologi. Melalui kegiatan ini, siswa dapat belajar coding secara bertahap mulai dari dasar hingga membuat proyek sederhana.

Coding Club juga menjadi tempat untuk mengembangkan kreativitas, kemampuan berpikir logis, kerja sama, dan kemampuan memecahkan masalah melalui berbagai kegiatan dan proyek teknologi.

Apa yang Dipelajari

  • HTML
  • CSS
  • JavaScript
  • Pemrograman Web
  • Git dan GitHub

Alur Mengikuti Coding Club

  1. Mengisi formulir pendaftaran
  2. Mengikuti pertemuan pertama
  3. Belajar dasar pemrograman
  4. Membuat proyek sederhana
  5. Presentasi hasil proyek

Kegiatan Coding Club

Belajar HTML

Siswa mempelajari dasar-dasar HTML untuk membuat struktur sebuah halaman website.

Membuat Website

Siswa membuat website sederhana dengan menerapkan materi pemrograman web yang telah dipelajari.

Project Showcase

Siswa mempresentasikan hasil proyek yang telah dibuat kepada anggota Coding Club lainnya.
